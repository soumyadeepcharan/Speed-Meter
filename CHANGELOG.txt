Features Implemented
--------------------
Network Speed Monitoring (service/, data/, notification/)
- SpeedMonitorService: foreground service (START_STICKY) that samples
  TrafficStats.getTotalRxBytes() and getTotalTxBytes() every 1 second on
  Dispatchers.Default. It computes download and upload bytes per second from
  the deltas and the elapsed time. Counters that fall or report UNSUPPORTED
  are treated as zero.
- Data formatting (data/Speed.kt): formatSpeed() shows KB/s with no decimals
  below 1,024 KB/s, and MB/s with one decimal above that. Speed holds down, up,
  and total as HumanSpeed(speedValue, speedUnit). getHumanSpeed() returns the
  matching value for "download", "upload", or total.
- NotificationHelper: channel "netspeed_channel" (IMPORTANCE_LOW, no badge),
  an ongoing, local-only, low-priority notification with a custom content view.
  Notification ID 1001.
- notification_layout.xml: total speed and unit on the left, and a details line
  with "Down" and "Up" values with units on the right.
- IconGenerator: draws the total speed and unit as a 96 x 96 white bitmap,
  used as the status bar small icon. Value text is 46sp, 38sp, or 30sp by
  digit count, and unit text is 20sp. Typeface: sans-serif-condensed bold for
  the value, default bold for the unit.

Settings (data/SettingsDataStore.kt)
- DataStore Preferences named "settings", with key "indicatorEnabled".
- Default value is false (indicator off on new installs).
- indicatorEnabledFlow(context) exposes the setting as a Flow, with an
  IOException fallback to empty preferences.
- setIndicatorEnabled(context, enabled) writes the setting.

Service Start Logic (MainActivity.kt)
- MainActivity requests POST_NOTIFICATIONS on API 33+ if it is not granted.
- startServiceIfEnabled() collects indicatorEnabledFlow in lifecycleScope and
  starts SpeedMonitorService (foreground service on API 26+) only when the
  saved value is true. This runs after the permission check, both when the
  permission is already granted and when the user responds to the prompt.
- On API 26 to 32, no permission is needed, so the same check runs directly.

Home Screen (ui/screens/IndicatorEnableSetting.kt)
- IndicatorEnableSetting: a ListItem titled "Enable indicator" with the
  supporting text "Show NetSpeed indicator in the status bar".
- The list item is not drawn until the saved value has loaded, which avoids a
  flicker of the wrong switch state on launch.
- Turning the switch on starts SpeedMonitorService. Turning it off stops it.
- Switch component (ui/screens/UiWidgets.kt): reusable Material 3 Switch with
  a check icon in the thumb when checked, a LongPress haptic after the state
  changes, and a configurable contentDescription.

More Screen (ui/screens/MoreScreen.kt)
- MoreScreen: a LazyColumn with three sections.
  - General: "Notification settings" opens Settings.ACTION_APP_NOTIFICATION_SETTINGS
    for this package.
  - Appearance: "Dark theme" switch, bound to the isDarkTheme state and
    onThemeToggle from MainActivity. It changes the theme immediately.
  - Support: "Help & feedback" (opens HelpFeedbackDialog) and "About" (opens
    AboutDialog, showing the app name, version, and the description "A
    lightweight data transfer speed monitor for Android.").
- HelpFeedbackDialog: "Suggest a feature" and "Report a bug" each open an
  ACTION_SENDTO intent addressed to sdcgroupofficial@gmail.com with a prefilled
  subject and body. The bug report template includes the app version, device
  model (Build.MODEL), device name (Build.DEVICE), and Android version and API
  level. A Cancel button closes the dialog.
- Dialogs use focus requests on open, merged semantics, and state layers for
  press feedback.

Layout (ui/screens/AdaptiveHomeMoreLayout.kt)
- SpeedMeterHomeMoreContent: a ListDetailPaneScaffold with Home as the list pane
  and More as the detail pane, driven by rememberListDetailPaneScaffoldNavigator.
- Compact and ExtraCompact width classes use one pane (maxHorizontalPartitions = 1).
  The floating bottom toolbar appears and switches panes: Home navigates to the
  List role and More navigates to the Detail role.
- Medium width and wider use two panes side by side (maxHorizontalPartitions = 2).
  The bottom toolbar is not shown.
- Panes use AnimatedPane for transitions.

Top Bar and Bottom Toolbar (ui/screens)
- TopAppBar.kt: SpeedMeterTopAppBar, a Material 3 TopAppBar titled from
  strings.xml with pinned scroll behaviour.
- BottomToolbar.kt: SpeedMeterBottomToolbar, a HorizontalFloatingToolbar with
  Home and More items, exit-always scroll behaviour from the bottom edge, and
  labels hidden on ExtraCompact windows (under 300dp wide).

Theming (ui/theme)
- ColorScheme.kt: LightColorScheme and DarkColorScheme built from the
  md_theme_* tokens in Color.kt. Used as the fallback scheme below API 31.
- Color.kt: Material 3 baseline palette tokens for light and dark schemes
  (primary, secondary, tertiary, error, surface containers, outline, scrim).
- Theme.kt: MyComposeApplicationTheme(darkTheme, dynamicColor = true).
  - Dynamic colour (Material You) on API 31+ when dynamicColor is true.
    Otherwise, LightColorScheme or DarkColorScheme.
  - System bar icon appearance follows the theme through WindowCompat's
    insets controller.
- Type.kt: base Typography with a bodyLarge style.
- MainActivity holds isDarkTheme with rememberSaveable, seeded from the system
  setting, and updates it from the More screen switch.

Layout Utilities (ui/utils)
- WindowSizeClass.kt: width classes (ExtraCompact < 300dp, Compact < 600dp,
  Medium < 840dp, Expanded < 1200dp, Large < 1600dp, ExtraLarge otherwise)
  and height classes (Compact < 480dp, Medium < 900dp, Expanded otherwise),
  with remember-based Composable helpers.
- WindowSizeDefaults.kt: supporting defaults for the window size helpers.

Adaptive App Icon
- Launcher icon in mipmap-anydpi-v26 and mipmap-anydpi-v33 (standard and round).
- Background: drawable/ and drawable-night/ ic_launcher_background.xml.
- Foreground: drawable/, drawable-v24/, drawable-night/, and
  drawable-night-v24/ ic_launcher_foreground.xml. Design: a 7-segment coloured
  circular gauge arc with a needle group.
- Monochrome: drawable/ic_launcher_monochrome.xml for Android 13+ themed icons.
- Source: assets/ic_launcher.svg.

Changes Since 0.4.0
-------------------
- Fixed: the speed service no longer starts on launch when the indicator is
  off. The saved setting is checked first.
- Changed: the indicator default is now off (was on). New installs start with
  the indicator off.
- Fixed: the Enable indicator switch no longer shows the wrong state briefly
  on launch.
- Changed: the fallback colour scheme (used below API 31, or when dynamic colour
  is off) moved from the Purple palette to the Material 3 baseline palette.
  Colour tokens are now in Color.kt, and the schemes are in ColorScheme.kt.
- Changed: the haptic feedback on the switch fires after the state change.
- Version bumped to 0.4.1 (versionCode 5).

- No unit or instrumented tests.
- Home screen content is not scrollable yet.
