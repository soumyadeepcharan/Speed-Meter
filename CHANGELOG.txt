Features Implemented
--------------------
Network Speed Monitoring (service/, data/, notification/)
- SpeedMonitorService: foreground service (START_STICKY). A single monitoring
  coroutine (guarded by isMonitoring) samples TrafficStats every 1 second on
  Dispatchers.Default. It computes download and upload bytes per second from
  the deltas and the elapsed time. Counters that fall or report UNSUPPORTED
  are treated as zero.
- Session data usage: the service records total and Wi-Fi byte counters when it
  starts. Each tick reports the difference since then.
  - Total = TrafficStats total RX + TX.
  - Wi-Fi (estimate) = (total RX − mobile RX) + (total TX − mobile TX), floored
    at zero.
  - Counts reset when the service restarts. They are not saved between sessions.
- Data formatting (data/Speed.kt):
  - formatSpeed(): KB/s with no decimals below 1,024 KB/s, MB/s with one
    decimal above that.
  - formatDataUsage(): "N B" below 1 KiB, "N.N KB" below 1 MiB, "N.NN MiB"
    below 1 GiB, and "N.NN GiB" above that.
  - Speed holds down, up, and total as HumanSpeed(speedValue, speedUnit).
- NotificationHelper: channel "netspeed_channel", named "Speed Meter" in system
  settings (IMPORTANCE_LOW, no badge). It posts an ongoing, local-only,
  low-priority notification with a custom content view. Notification ID 1001.
- notification_layout.xml: an 18dp icon area with the total speed value and
  unit, and one details line: "Data", "WiFi", "Down", and "Up" with their values.
- IconGenerator: draws the total speed and unit as a 72 x 96 white bitmap, used
  as the status bar small icon. Value text is 60sp, 48sp, or 38sp by digit
  count. Unit text is 28sp, sans-serif-black bold.

Settings (data/SettingsDataStore.kt)
- DataStore Preferences named "settings".
- indicatorEnabled (Boolean, default false): indicatorEnabledFlow and
  setIndicatorEnabled.
- themeMode (Int, default 0 = SYSTEM): themeModeFlow and setThemeMode.
- ThemeMode enum: SYSTEM(0), LIGHT(1), DARK(2). fromStorageValue() falls back to
  SYSTEM for unknown values.
- Both flows fall back to empty preferences on IOException.

Service Start Logic (MainActivity.kt)
- MainActivity requests POST_NOTIFICATIONS on API 33+ if it is not granted.
- startServiceIfEnabledOnce() reads indicatorEnabledFlow().first() in
  lifecycleScope and starts SpeedMonitorService (foreground service on API
  26+) only when the saved value is true. It reads the value once.
- The same check runs after the permission prompt is answered (if granted) and
  directly on API 26 to 32.

Single Page (ui/HomeScreen.kt)
- SpeedMeterHomeMoreContent: one Surface containing a LazyColumn with two items,
  HomeScreen first and MoreScreen after it. Vertical spacing is 16dp.
- The bottom floating toolbar and the two-pane list-detail layout were removed.
  Home and More are reached by scrolling.

Home Section (ui/HomeScreen.kt, HomeScreen)
- An "Indicator" section with a single row: NetworkCheck icon, the title
  "Enable indicator", the subtitle "Show network speed in the status bar", and a
  switch. Tapping the whole row toggles the setting (Role.Switch).
- The row is not drawn until the saved value has loaded.
- Turning it on starts SpeedMonitorService. Turning it off stops it.

More Section (ui/HomeScreen.kt, MoreScreen)
- A LazyColumn-based section with four parts.
  - General: "Notification settings" opens Settings.ACTION_APP_NOTIFICATION_SETTINGS
    for this package.
  - Appearance: "Choose theme" opens ThemeDialog. The row subtitle shows the
    current choice: "System default", "Light mode", or "Dark mode". The dialog
    uses radio buttons, and selecting one saves it with setThemeMode.
  - Support: "Help & feedback" (HelpFeedbackDialog) and "About" (AboutDialog).
  - Footer: "Made with ❤️ from India by SDC Group".
- HelpFeedbackDialog: "Suggest a feature" and "Report a bug" each open an
  ACTION_SENDTO intent addressed to sdcgroupofficial@gmail.com with a prefilled
  subject and body from strings.xml. The dialog title is "How can you help?".
  The bug report template includes the app version, device model
  (Build.MODEL), device name (Build.DEVICE), and Android version and API level.
- AppAlertDialog (ui/UiWidgets.kt): shared Material 3 AlertDialog wrapper with a
  confirm-button variant and a dismiss-button variant, and a content description.

Theming (ui/)
- Color.kt: Material 3 baseline palette tokens (md_theme_*), plus
  LightColorScheme and DarkColorScheme. These are the fallback schemes used when
  dynamic colour is off or the device is below API 31.
- Theme.kt: MyComposeApplicationTheme(themeMode, dynamicColor = true).
  - darkTheme is resolved from ThemeMode: SYSTEM uses isSystemInDarkTheme(),
    LIGHT uses false, DARK uses true.
  - Dynamic colour (Material You) on API 31+ when dynamicColor is true.
  - System bar icon appearance follows the resolved theme through WindowCompat's
    insets controller.
- Type.kt: base Typography with a bodyLarge style.

Top Bar (ui/TopAppBar.kt)
- SpeedMeterTopAppBar: a Material 3 TopAppBar titled from strings.xml with pinned

Layout Utilities (ui/)

Known Limitations
-----------------
- Data usage is per session. Counters reset when the service restarts (after a
  reboot, a force stop, or turning the indicator off and on). Daily totals are
  not saved yet.
- The Wi-Fi figure is an estimate (total minus mobile). It may include other
  non-mobile interfaces such as Ethernet or VPN traffic.
- On devices where TrafficStats mobile counters are unsupported, the Wi-Fi
  estimate equals total traffic.
- Material 3 1.5.0-alpha03 is a pre-release and may show visual quirks.
- The Material 3 Adaptive libraries are still declared but not used.
- No bottom navigation. Home and More share one scrolling page.
- No speed history, speedometer gauge, or units setting.
- No About screen beyond the dialog. No separate settings screen.
- No unit or instrumented tests.
- No animated launcher icon (the animated drawable is not in this build).
