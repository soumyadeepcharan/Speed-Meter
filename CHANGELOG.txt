Features Implemented
--------------------
Network Speed Monitoring (service/, data/, notification/)
- SpeedMonitorService: foreground service (START_STICKY) that samples
  TrafficStats.getTotalRxBytes() and getTotalTxBytes() every 1 second on
  Dispatchers.Default. It computes download and upload bytes per second from
  the deltas and the elapsed time. Counters that fall or report UNSUPPORTED
  are treated as zero.
- Data formatting (data/Speed.kt): formatSpeed() shows KB/s with no decimals
  below 1,024 KB/s, and MB/s with one decimal above that. Speed holds down, up,
  and total as HumanSpeed(speedValue, speedUnit). getHumanSpeed() returns the
  matching value for "download", "upload", or total.
- NotificationHelper: channel "netspeed_channel" (IMPORTANCE_LOW, no badge),
  an ongoing, local-only, low-priority notification with a custom content view.
  Notification ID 1001.
- notification_layout.xml: total speed and unit on the left, and a details line
  with "Down" and "Up" values with units on the right.
- IconGenerator: draws the total speed and unit as a 96 x 96 white bitmap,
  used as the status bar small icon. Value text is 46sp, 38sp, or 30sp by
  digit count, and unit text is 20sp. Typeface: sans-serif-condensed bold for
  the value, default bold for the unit.

Settings (data/SettingsDataStore.kt, ui/screens/IndicatorEnableSetting.kt)
- DataStore Preferences named "settings", with key "indicatorEnabled"
  (Boolean, default true).
- indicatorEnabledFlow(context) exposes the setting as a Flow, with an IOException
  fallback to empty preferences.
- setIndicatorEnabled(context, enabled) writes the setting.
- IndicatorEnableSetting: a ListItem titled "Enable indicator" with the
  supporting text "Show NetSpeed indicator in the status bar". Turning it on
  starts the service, and turning it off stops it.
- Switch component (ui/screens/UiWidgets.kt): reusable Material 3 Switch with
  a check icon in the thumb when checked, a LongPress haptic on toggle, and a
  configurable contentDescription (here "Toggle NetSpeed status bar indicator").

Main Screen (MainActivity.kt, ui/screens)
- MainActivity requests POST_NOTIFICATIONS on API 33+ if it is not granted, and
  starts the service when granted. On API 26 to 32 it starts the service
  directly.
- SpeedMeterApp: wraps the screen in MyComposeApplicationTheme and a Material 3
  Scaffold with:
  - Top bar (TopAppBar.kt, SpeedMeterTopAppBar) titled from strings.xml, with
    pinned scroll behaviour. It does not render a theme toggle yet.
  - Body: a Box containing a Surface with IndicatorEnableSetting, and the
    bottom toolbar aligned to BottomCenter.
- Bottom toolbar (BottomToolbar.kt, SpeedMeterBottomToolbar): a
  HorizontalFloatingToolbar with Home and More items, exit-always scroll
  behaviour from the bottom edge, and labels hidden on ExtraCompact windows
  (under 300dp wide). Click handlers are empty placeholders.

Theming (ui/theme)
- Color.kt: Purple, PurpleGrey and Pink palettes used as the fallback scheme.
- Theme.kt: MyComposeApplicationTheme(darkTheme, dynamicColor = true).
  - Light and dark schemes. Dynamic colour (Material You) on API 31+.
  - System bar icon appearance follows the theme through WindowCompat's
    insets controller.
- Type.kt: base Typography with a bodyLarge style.
- The dark mode state in SpeedMeterApp is held with rememberSaveable and
  seeded from the system setting. No visible control changes it yet.

Layout Utilities (ui/utils)
- WindowSizeClass.kt: width classes (ExtraCompact < 300dp, Compact < 600dp,
  Medium < 840dp, Expanded < 1200dp, Large < 1600dp, ExtraLarge otherwise)
  and height classes (Compact < 480dp, Medium < 900dp, Expanded otherwise),
  with remember-based Composable helpers.
- WindowSizeDefaults.kt: supporting defaults for the window size helpers.

Adaptive App Icon
- Launcher icon in mipmap-anydpi-v26 and mipmap-anydpi-v33 (standard and round).
- Background: drawable/ and drawable-night/ ic_launcher_background.xml.
- Foreground: drawable/, drawable-v24/, drawable-night/, and
  drawable-night-v24/ ic_launcher_foreground.xml. Design: a 7-segment coloured
  circular gauge arc with a needle group.
- Monochrome: drawable/ic_launcher_monochrome.xml for Android 13+ themed icons.
- Source: assets/ic_launcher.svg.

Known Limitations and Issues
----------------------------
- Known issue: MainActivity starts SpeedMonitorService on every launch, without
  checking the indicatorEnabled setting. If the user turns the indicator off
  and then opens the app, the service starts again while the switch shows off.
  The fix is to read the saved setting before starting the service.
- The Home and More toolbar buttons have empty click handlers.
- No visible theme toggle. SpeedMeterTopAppBar does not render the ThemeSwitch
  component, and the dark mode state cannot be changed by the user.
- Material 3 1.5.0-alpha03 is a pre-release and may show visual quirks.
- Daily data usage tracking is not implemented.
- No speed history, speedometer gauge, or settings screen beyond the indicator
  switch.
- No About screen.
- No unit or instrumented tests.
- No DataStore-backed unit or theme preference.
- No animated launcher icon (the animated drawable is not in this build).
- Pinned scroll behaviour and the bottom toolbar's exit-always scroll have no
  effect until scrollable content exists.
